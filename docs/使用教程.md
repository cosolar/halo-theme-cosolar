# halo-theme-cosolar 主题使用与配置手册

> 一款为开发者打造的现代 Halo 博客主题：青绿美学、明暗双模、精选轮播、动态背景、全局搜索、完美移动端适配。
>
> 适用版本：Halo `>= 2.25.0` ｜ 主题版本：`1.1.6`（本手册以此版本为准）

本手册以主题后台 **设置（cosolar-setting）** 中的全部配置项为基准，逐项说明每个字段的含义、默认值、取值范围与配置建议；并补充菜单图标、文章注解、依赖插件等「设置界面之外」的实用功能。读完即可独立完成从安装到精调的全过程。

## 1. 安装与启用

### 环境要求

| 项目                      | 要求                                                          |
| ------------------------- | ------------------------------------------------------------- |
| Halo                      | `>= 2.25.0`                                                   |
| Node / pnpm（仅源码构建） | Node `>= 18`、pnpm `>= 8`                                     |
| 浏览器                    | 现代浏览器（Chrome / Edge / Firefox / Safari 最近两个大版本） |

### 方式一：上传 ZIP（推荐）

1. 在主题 Release 页面下载最新 `cosolar-<version>.zip`（也可使用本仓库 `dist/` 目录下打包好的 zip）。
2. 登录 Halo 后台，进入 **主题管理 → 安装主题**，选择「上传主题」并选择 ZIP 文件。
3. 安装完成后，在主题列表找到 **halo-theme-cosolar**，点击 **启用**。
4. 启用后访问站点首页，应能看到默认青绿配色与动态背景效果。

> 小贴士：若上传时报「主题已存在」，可在主题管理界面先卸载旧版本再上传；或直接覆盖安装（保留你已配置的设置项）。

### 方式二：源码构建

适合二次开发或需要本地预览的用户。

```bash
# 1. 安装依赖（pnpm install 会自动触发 prepare 脚本完成初始化）
pnpm install

# 2. 开发模式：监听 src/ 变化并实时输出到 templates/
pnpm dev

# 3. 验证编译是否通过（类型检查 + 构建）
pnpm build-only

# 4. 正式构建，产物包括 templates/ 与 dist/cosolar-<version>.zip
pnpm build
```

构建完成后，将 `dist/halo-theme-cosolar.zip` 上传到 Halo；或直接把整个项目目录放入 Halo 工作目录的 `themes/halo-theme-cosolar/` 下，再到后台启用。

### 方式三：Halo 应用市场

若主题已上架 Halo 应用市场，可在后台 **主题管理 → 安装主题 → 应用市场** 中搜索 `cosolar`，点击安装即可（最省事，但版本可能略落后于 GitHub Release）。

### 启用后必做事项

| 步骤                                                                  | 目的                                           |
| --------------------------------------------------------------------- | ---------------------------------------------- |
| 进入 **外观 → 菜单**，新建或导入菜单                                  | 主题导航栏依赖 Halo 菜单系统，无菜单时导航为空 |
| 进入 **设置 → 主题设置 → halo-theme-cosolar**，填写 Logo 文字、标语等 | 留空虽可用默认值，但站点身份信息建议尽早填写   |
| 安装 `plugin-links`（如需友链 / RSS 资讯页）                          | 见 [23. 依赖插件与搜索](#23-依赖插件与搜索)    |
| 安装 `PluginSearchWidget`（如需全局搜索框）                           | 同上                                           |
| 安装 [`plugin-minidocs`](https://github.com/cosolar/halo-plugin-minidocs/releases)（如需知识库页）、`plugin-photos`（如需图库页） | 同上                                           |

## 2. 配置入口与基本概念

启用主题后，进入 **Halo 后台 → 主题管理 → halo-theme-cosolar → 设置**，即可看到按分组排列的所有配置项。每个分组对应 `settings.yaml` 中的一个 `formSchema`，分组名（如 `basic`、`footer`）即为内部键名。

### 三个重要约定

> **约定一：留空即默认**
>
> 绝大多数文本 / 图片 / 颜色字段留空时，主题会使用内置默认效果（如默认 `</>` 代码图标 Logo、默认青绿渐变背景、默认字体等）。**不确定时先留空观察效果**，比盲目填一个值更安全。

> **约定二：明暗双模独立**
>
> 背景图、博主卡片、页脚、登录页等视觉项普遍提供「浅色模式 / 深色模式」两套独立配置。当访客或系统切换主题时，会自动套用对应的一套，两套互不影响。**如果你只想配置浅色模式，深色模式那栏可以全部留空**（主题会回退到合理的默认值）。

> **约定三：附件字段值是 URL**
>
> 所有 `$formkit: attachment` 类型的字段，后台表现为「上传图片」按钮，存储的值是该图片在 Halo 中的访问 URL。在模板中可直接 `src="${theme.config?.footer?.bg_image}"` 使用。

### 配置项表格说明

下文每个分组的配置项均以表格形式列出，列含义如下：

| 列名       | 含义                         |
| ---------- | ---------------------------- |
| 配置项     | 后台显示的配置项名称         |
| 类型       | 字段输入类型                 |
| 默认值     | 留空时的内置默认效果         |
| 说明与建议 | 字段作用、取值范围、配置建议 |

## 3. 基础设置（basic）

配置站点身份信息，显示在导航栏左侧与全局。

| 配置项        | 类型 | 默认值                       | 说明与建议                                                                          |
| ------------- | ---- | ---------------------------- | ----------------------------------------------------------------------------------- |
| Logo 图片     | 附件 | 空                           | 导航栏左侧 Logo；留空显示 `</>` 代码图标。建议透明背景 PNG / SVG，源图尺寸 72–160px |
| Logo 图片宽度 | 数字 | 36                           | 显示宽度（px），范围 20–80，步长 2。建议等于或略小于高度                            |
| Logo 图片高度 | 数字 | 36                           | 显示高度（px），范围 20–80，步长 2                                                  |
| Logo 文字     | 文本 | `码迹志`                     | 导航栏紧邻 Logo 的站点名称，2–6 个字最佳；过长会在窄屏截断                          |
| 站点标语      | 文本 | `记录技术成长，分享解决方案` | Logo 文字下方的小号副标题，可留空隐藏                                               |

### 配置示例

- **纯文字站点**：`logo_image` 留空，`logo_text` 填 `码迹志`，`tagline` 填一句话简介。导航栏将显示 `</>` 图标 + 文字 + 标语。
- **带图片 Logo**：上传一张透明 PNG，设 `logo_image_width=40`、`logo_image_height=40`，`logo_text` 留空或填站点名。

> 页脚版权文字（`footer_text`）与 ICP 备案号（`icp`）已迁移至「页脚设置」分组，本组不再包含。

## 4. 页脚设置（footer）

控制页脚的品牌区、统计区、订阅区、底部版权与备案信息。页脚同样区分浅色 / 深色两套背景配置。

### 4.1 通用页脚配置

| 配置项               | 类型     | 默认值 | 说明与建议                                                                 |
| -------------------- | -------- | ------ | -------------------------------------------------------------------------- |
| 显示页脚主区域       | 开关     | true   | 关闭后隐藏页脚的品牌、统计、订阅主区域，仅保留底部版权信息                 |
| 显示 Powered by 信息 | 开关     | true   | 关闭后隐藏页脚底部的「Powered by Halo」与主题信息                          |
| 页脚版权文字         | 多行文本 | 空     | 页脚底部的版权信息，**支持 HTML**，可插入链接、图标等                      |
| ICP 备案号           | 文本     | 空     | 如：`京ICP备XXXXXXXX号`；会自动生成到工信部备案查询的链接                  |
| 页脚 Logo 图片       | 附件     | 空     | 页脚品牌区显示的 Logo；留空则回退到「基础设置」中的 Logo 或默认 `</>` 图标 |
| 页脚 Logo 宽度       | 数字     | 36     | 范围 20–80，步长 2                                                         |
| 页脚 Logo 高度       | 数字     | 36     | 范围 20–80，步长 2                                                         |
| 页脚 Logo 显示名称   | 文本     | 空     | 页脚品牌区显示的名称；留空回退到「基础设置」的 `logo_text`                 |
| 页脚标语             | 文本     | 空     | 页脚品牌区标语；留空回退到站点标语                                         |
| 页脚站点简介         | 多行文本 | 空     | 页脚品牌区下方的站点简介；留空回退到页脚标语                               |

![img.png](img/img2.png)

### 4.2 浅色模式（footer.light）

| 配置项         | 类型 | 默认值 | 说明与建议                                                                                   |
| -------------- | ---- | ------ | -------------------------------------------------------------------------------------------- |
| 页脚背景图片   | 附件 | 空     | 建议浅色调、低饱和度图片，避免影响内容阅读；留空则不显示背景图                               |
| 背景图片透明度 | 滑块 | 0.2    | 范围 0.05–1，步长 0.05；值越小背景图越淡，文字越清晰                                         |
| 文字与图标颜色 | 颜色 | 空     | 页脚品牌区文字（名称、标语、简介）及社交图标的颜色；**留空则使用主题默认文字色**（跟随明暗） |

### 4.3 深色模式（footer.dark）

> 深色模式下背景图与透明度**留空即复用浅色模式的取值**，只有需要单独效果时才填。

| 配置项         | 类型 | 默认值 | 说明与建议                                                     |
| -------------- | ---- | ------ | -------------------------------------------------------------- |
| 页脚背景图片   | 附件 | 空     | 深色模式下建议使用低调暗色背景图；留空复用浅色模式的背景图     |
| 背景图片透明度 | 滑块 | 0.2    | 范围 0.05–1，步长 0.05；留空复用浅色模式的透明度               |
| 文字与图标颜色 | 颜色 | 空     | 深色模式下页脚品牌区文字及社交图标颜色；留空复用浅色模式的颜色 |

### 4.4 页脚导航链接（footer.legal_links）

页脚底部的四组小字链接，**每组由一个「显示」开关与一个「地址」字段构成**，关闭开关或留空地址即不显示该条：

| 配置项           | 类型 | 默认值     | 说明与建议                       |
| ---------------- | ---- | ---------- | -------------------------------- |
| 显示「隐私政策」 | 开关 | true       | 关闭后不再显示该链接             |
| 隐私政策页面地址 | URL  | `/privacy` | 站内相对路径或外链；留空则不显示 |
| 显示「使用条款」 | 开关 | true       | 同上                             |
| 使用条款页面地址 | URL  | `/terms`   | 同上                             |
| 显示「友情链接」 | 开关 | true       | 同上                             |
| 友情链接页面地址 | URL  | `/links`   | 同上                             |
| 显示「关于我们」 | 开关 | true       | 同上                             |
| 关于我们页面地址 | URL  | `/about`   | 同上                             |

> 链接文案固定为「隐私政策 / 使用条款 / 友情链接 / 关于我们」，暂不支持自定义名称；四项均按添加顺序排列显示。

### 4.5 服务商 / 赞助商（footer.sponsor）

页脚底部的一条赞助展示（形如「本网站由 **腾讯云** 提供CDN加速/云服务」），默认关闭。

| 配置项             | 类型 | 默认值               | 说明与建议                                                                         |
| ------------------ | ---- | -------------------- | ---------------------------------------------------------------------------------- |
| 显示服务商信息     | 开关 | false                | 总开关，开启后才在页脚底部渲染服务商条目                                           |
| 服务商图标         | 文本 | `ri:cloud-line`      | 填 **Iconify 图标名**（如 `ri:cloud-line`、`ri:tencent-cloud-line`）或完整图片 URL |
| 服务商名称         | 文本 | 空                   | 显示文案，如 `腾讯云`、`阿里云`、`京东云`                                          |
| 服务商链接         | URL  | 空                   | 点击服务商名称跳转的地址；留空则显示为纯文本                                       |
| 前缀文字           | 文本 | `本网站由`           | 服务商名称之前显示的文字                                                           |
| 后缀文字           | 文本 | `提供CDN加速/云服务` | 服务商名称之后显示的文字                                                           |
| 服务商名称为超链接 | 开关 | true                 | 关闭后服务商名称不可点击，仅显示纯文本                                             |

> 图标名需与「主题样式 → 图标库」匹配；Iconify 图标可在 [icon-sets.iconify.design](https://icon-sets.iconify.design) 搜索。

### 4.6 订阅表单（footer.footer_subscribe_action）

| 配置项           | 类型 | 默认值 | 说明与建议                                                               |
| ---------------- | ---- | ------ | ------------------------------------------------------------------------ |
| 订阅表单提交地址 | URL  | 空     | 第三方邮件订阅服务地址（如 Mailchimp）；留空则仅展示表单，不执行提交动作 |

### 配置示例

- **最简页脚**：`show_footer_main` 关闭，仅保留底部一行版权（`footer_text` 填 `© 2026 码迹志`）。
- **完整品牌页脚**：上传页脚 Logo，填站点标语与简介，开启 `show_footer_main` 与 `show_footer_powered`。
- **带备案号**：`icp` 填 `京ICP备12345678号-1`，页脚底部会自动渲染为可点击的工信部链接。
- **展示赞助商**：`sponsor.enabled=true`，`name=腾讯云`，`url=https://cloud.tencent.com`，`icon=ri:tencent-cloud-line`，`prefix=本网站由`，`suffix=提供云服务`。

> `footer_text` 支持 HTML，但请勿粘贴未受信任的脚本；Halo 的设置值不会自动转义，主题模板会按 HTML 渲染。

## 5. 主题样式（style）

控制全站主题色、版式宽度、字体、图标库等基础视觉变量。这是个性化最直接的一组配置。

| 配置项            | 类型 | 默认值             | 说明与建议                                                                                         |
| ----------------- | ---- | ------------------ | -------------------------------------------------------------------------------------------------- |
| 主题色            | 颜色 | `#10B981`          | 主色调，用于按钮、链接、标签、选中态等强调元素。建议使用与默认青绿系相近的色相，避免与正文颜色冲突 |
| 默认配色方案      | 单选 | `auto`（跟随系统） | 可选 `auto` / `light` / `dark`。`auto` 会根据访客系统偏好自动切换明暗                              |
| 内容最大宽度      | 数字 | 1600               | 页面内容区最大宽度（px），范围 960–1920，步长 20。文字密度高的博客建议 1200–1400                   |
| 侧边栏宽度        | 数字 | 320                | 右侧侧边栏宽度（px），范围 260–400，步长 10                                                        |
| 内容间距          | 数字 | 24                 | 内容区与侧边栏之间的间距（px），范围 12–48，步长 2                                                 |
| 正文字体族        | 文本 | 空                 | 自定义正文字体族（CSS `font-family` 语法）；留空使用默认霞鹜文楷。例：`"Noto Sans SC", sans-serif` |
| 字体 CSS 地址     | URL  | 空                 | 第三方字体 CSS 链接（Google Fonts、字节跳动 FontAPI 等）；留空使用默认霞鹜文楷 CDN                 |
| 等宽字体族        | 文本 | 空                 | 自定义代码 / 等宽字体族；留空使用默认 JetBrains Mono                                               |
| 等宽字体 CSS 地址 | URL  | 空                 | 第三方等宽字体 CSS 链接；留空则不额外加载                                                          |
| 图标库            | 单选 | `iconify`          | `iconify`（图标最全，开箱即用）或 `iconfont`（自定义图标，需在 iconfont.cn 创建项目）              |
| iconfont CSS 地址 | URL  | 空                 | 仅 `iconfont` 模式生效，填自建 iconfont 项目 CSS 地址。Iconify 模式下忽略                          |

### 配置示例

**示例一：经典青绿（默认）**

- `primary_color` = `#10B981`，`color_scheme` = `auto`，字体全留空。
- 效果：默认青绿配色，跟随系统明暗，霞鹜文楷正文 + JetBrains Mono 代码。

**示例二：自托管字体（完全离线）**

1. 下载字体文件，上传到 Halo **附件管理**。
2. 复制附件 URL，将其填入 `font_css_url`（如果只有字体文件而非 CSS，可自建一个 `@font-face` CSS 文件并上传）。
3. `font_family` 填写对应的字体族名称，如 `"LXGW WenKai", serif`。

**示例三：改用 iconfont 自定义图标**

1. 在 [iconfont.cn](https://www.iconfont.cn) 创建项目，添加所需图标，发布得到 CSS 地址（形如 `https://at.alicdn.com/t/c/xxx.css`）。
2. `icon_provider` 设为 `iconfont`，`icon_css_url` 填上一步地址。
3. 此后所有图标类名按 iconfont 规则填写（如 `icon-github`）。菜单图标见 [20. 菜单图标配置](#20-菜单图标配置注解)。

> **代码高亮**：代码高亮主题由 Halo 官方 `plugin-shiki` 插件在后台配置（亮色 / 暗色主题），主题本身不提供该选项。请确保已安装该插件，并在插件设置中选择合适的亮暗高亮主题。

## 6. 博主信息（social）

显示在页脚博主卡片与侧边栏博主卡片上的个人信息。`author_social_links` 为可增删的数组，每个元素是一个社交图标。

### 6.1 基础信息

| 配置项       | 类型     | 默认值 | 说明与建议                                         |
| ------------ | -------- | ------ | -------------------------------------------------- |
| 博主昵称     | 文本     | 空     | 页脚博主卡片的昵称；留空使用站点标题               |

## 16. 知识库页设置（docs）

控制知识库列表页（`/docs`）的统计栏、左侧信息侧栏与数据量。**本页面依赖 `plugin-minidocs` 插件**（MiniDocs，下载地址：[halo-plugin-minidocs Releases](https://github.com/cosolar/halo-plugin-minidocs/releases)），未安装时访问 `/docs` 返回 404 或由插件内置模板渲染。

> MiniDocs 插件提供三组前台路由：`/docs`（知识库列表）、`/docs/view/{kbSlug}`（知识库阅读页，含文档树 + 正文 + 目录三栏布局）、`/docs/share/{shareToken}`（外链分享页）。主题通过同名模板 `docs.html` / `doc.html` 覆盖了前两个路由，分享页使用插件内置默认模板。详细 Finder API 与类型定义见 [`minidocs-theme-api.md`](./minidocs-theme-api.md)。

### 16.1 通用配置

| 配置项           | 类型 | 默认值 | 说明与建议                                                                                       |
| ---------------- | ---- | ------ | ------------------------------------------------------------------------------------------------ |
| 显示统计栏       | 开关 | true   | 列表页顶部显示统计数据栏（知识库总数、文档总数、标签数量、访问量、点赞量）；关闭后隐藏整个统计栏 |
| 显示左侧边栏     | 开关 | true   | 列表页左侧显示信息侧栏（今日动态、最近更新、标签分类）；关闭后内容区占满宽度                     |
| 最近更新显示条数 | 数字 | 5      | 范围 1–20，步长 1；侧栏「最近更新」模块显示条目数量，超出部分在模块内滚动                        |
| 标签云显示条数   | 数字 | 10     | 范围 1–50，步长 1；侧栏「标签分类」模块显示标签数量，超出部分在模块内滚动                        |

### 16.2 列表页功能说明（无需配置项）

以下功能为内置行为，不依赖设置项：

- **搜索筛选**：工具栏搜索框支持按知识库名称 / 描述 / 标签 / 创建者实时过滤；按 `/` 键可快速聚焦搜索框
- **快捷筛选**：侧栏「标签云」中的标签与「今日动态」中的创建者均可点击，作为筛选条件叠加使用
- **排序方式**：支持「最近更新」「文档最多」「名称 A-Z」「最新创建」四种排序
- **视图切换**：卡片视图（封面 + 摘要）与列表视图（紧凑行）一键切换
- **点赞交互**：每个知识库卡片右上角可点击爱心图标点赞；**匿名访客也可点赞**，按浏览器本地记录去重（同一浏览器只能点一次，与阅读页共用记录）
- **分页**：默认每页 9 个知识库，底部页码分页，与筛选 / 排序 / 视图状态联动
- **空状态提示**：无匹配结果时显示「暂无公开知识库」及「清除筛选条件」按钮

### 16.3 阅读页功能说明（无需配置项）

阅读页（`/docs/view/{kbSlug}`）提供：

- **顶部工具条**：返回知识库链接、加入浏览器书签、复制当前页链接、点赞（含匿名点赞，本地去重）、访问量统计
- **左侧文档树**：递归展示该知识库已发布文档树，支持展开 / 收起子节点、按标题搜索、高亮并自动滚动到当前文档
- **中间正文区**：渲染文档正文（HTML），支持代码块复制等富文本增强
- **右侧目录**：自动提取正文标题（H1–H6）生成大纲，滚动时高亮当前小节，可点击跳转
- **底部信息栏**：文档路由路径、正文字数 / 行数、作者、创建与更新时间、「回到顶部」按钮
- **可拖拽调整**：左侧文档树（200–520px）与右侧目录（170–480px）均支持拖拽调整宽度

### 配置示例

- **极简列表页**：`show_stats=false`，`show_sidebar=false`，仅保留卡片网格与分页。
- **数据丰富的侧栏**：`recent_count=8`，`tag_count=20`，让访客一眼看到最新动态与热门标签。
- **纯展示模式**：关闭所有操作入口（阅读页无编辑功能），仅展示已发布文档——MiniDocs 的 Finder 只返回 `phase=published` 的文档，未登录用户仅能访问公开知识库。

> 若访问 `/docs` 时出现 404 或空白，请确认：
>
> 1. 已安装并启用 `plugin-minidocs` 插件；
> 2. 在插件设置中开启「允许未登录用户阅读」（如需游客可浏览公开知识库）；
> 3. 至少创建一个公开知识库并发布一篇文档。

## 17. 页面背景（background）

控制全站页面背景，浅色 / 深色模式各有一套独立配置。背景类型分三类：**无（默认纯色）**、**自定义背景图**、**动态渲染背景**。

### 17.1 浅色模式（background.light）

| 配置项         | 类型 | 默认值                  | 说明与建议                                                                                                |
| -------------- | ---- | ----------------------- | --------------------------------------------------------------------------------------------------------- |
| 背景类型       | 单选 | `none`                  | `none` 纯色 / `image` 自定义图 / `dynamic` 动态渲染                                                       |
| 背景图         | 附件 | 空                      | 建议浅色调、低饱和度图片，避免影响阅读                                                                    |
| 背景图透明度   | 滑块 | 0.2                     | 范围 0.05–1，步长 0.05；值越小越淡                                                                        |
| 动态背景类型   | 单选 | `particles`（粒子连线） | 可选 `particles` / `gradient`（渐变流光）/ `bubbles`（气泡漂浮）/ `stars`（星空闪烁）/ `mesh`（网格波纹） |
| 动态背景主色   | 颜色 | `#10B981`               | 动态背景主要颜色                                                                                          |
| 动态背景辅色   | 颜色 | `#3B82F6`               | 辅助颜色，用于渐变与混合                                                                                  |
| 动态背景透明度 | 滑块 | 0.15                    | 范围 0.05–0.5，步长 0.05；值越小越淡                                                                      |

### 17.2 深色模式（background.dark）

| 配置项         | 类型 | 默认值              | 说明与建议         |
| -------------- | ---- | ------------------- | ------------------ |
| 背景类型       | 单选 | `none`              | 同浅色模式         |
| 背景图         | 附件 | 空                  | 建议使用深色调图片 |
| 背景图透明度   | 滑块 | 0.2                 | 同浅色模式         |
| 动态背景类型   | 单选 | `stars`（星空闪烁） | 同浅色模式         |
| 动态背景主色   | 颜色 | `#10B981`           | 同浅色模式         |
| 动态背景辅色   | 颜色 | `#3B82F6`           | 同浅色模式         |
| 动态背景透明度 | 滑块 | 0.15                | 同浅色模式         |

### 配置示例

**示例一：深色模式星空 + 浅色模式纯色**

- `background.light.bg_type=none`，`background.dark.bg_type=dynamic`，`bg_dynamic_type=stars`。
- 效果：白天干净纯色，夜晚深邃星空闪烁。

**示例二：双模同款淡彩背景图**

- 两个模式都设 `bg_type=image`，分别上传浅 / 深色调横图，`bg_image_opacity=0.15`。
- 效果：背景图极淡，仅作氛围烘托，不影响正文阅读。

> 动态背景基于 Canvas 2D 渲染，粒子数随屏幕自动调整，性能开销极小。如访客设备性能受限，可改用静态背景图。

## 21. 文章自定义阅读地址（注解）

文章支持一个 **Post 注解** `reading_url`：

1. 后台 **文章 → 文章管理** → 编辑某篇文章
2. 在文章 **注解** 中添加字段 `reading_url`，填入外部地址（如外部博客 / 第三方平台）
3. 保存后，前台文章卡片的「阅读全文」将跳转到该地址；留空则使用默认文章链接

### 使用场景

- **多平台同步发文**：主站只放摘要，`reading_url` 指向微信公众号原文，主站引流。
- **付费墙 / 第三方平台**：把详细内容托管在第三方平台，`reading_url` 指向该平台文章页。

> 注解只影响前台文章卡片的「阅读全文」链接，不会改变 Halo 文章详情页本身的访问地址。

| 插件           | 用途                                            | 必需度                                            |
| -------------- | ----------------------------------------------- | ------------------------------------------------- |
| `plugin-links` | 管理友链、检测可达性与回链、聚合友站 RSS / Atom | 友链页、侧边栏友链 / 订阅模块、RSS 资讯页**必需** |

**未安装时表现**：友链页列表为空、侧边栏「友情链接」「订阅资讯」模块自动隐藏、RSS 资讯页显示「未启用」提示。

**安装后还需**：在插件「RSS 订阅」中开启「公开 RSS 订阅动态」，RSS 资讯页与侧边栏订阅模块才有内容。

### 23.2 搜索功能依赖官方搜索插件

| 插件                 | 用途                      | 必需度           |
| -------------------- | ------------------------- | ---------------- |
| `PluginSearchWidget` | 提供全站文章 / 页面搜索框 | 全局搜索**必需** |

**配置步骤**：

1. 在 Halo 应用市场搜索并安装 `PluginSearchWidget`。
2. 启用插件后，导航栏自动显示搜索框，支持 `Ctrl+K`（macOS `⌘+K`）快捷键唤起。
3. 未安装时搜索框降级为归档页链接，导航栏不会报错。

### 23.3 图库页依赖 `plugin-photos`

| 插件            | 用途                             | 必需度         |
| --------------- | -------------------------------- | -------------- |
| `plugin-photos` | 官方图库插件，提供照片管理与分组 | 图库页**必需** |

**未安装时表现**：图库页无照片数据、`/photos` 路由不可用。

> 旧版本侧边栏中的「显示图库模块」开关已移除，图库内容统一由图库页承载；若你在旧版配置过该开关，可忽略。

### 23.4 知识库页依赖 `plugin-minidocs`

| 插件              | 用途                                                          | 必需度           |
| ----------------- | ------------------------------------------------------------- | ---------------- |
| `plugin-minidocs` | MiniDocs 知识库插件，提供知识库 / 文档模型与 `minidocsFinder` | 知识库页**必需** |

**未安装时表现**：`/docs`、`/docs/view/{kbSlug}` 路由不可用（404）。

> 📥 插件下载地址：[`halo-plugin-minidocs` Releases](https://github.com/cosolar/halo-plugin-minidocs/releases)

**安装后还需**：

1. 在插件设置中开启「允许未登录用户阅读」（如需游客可浏览公开知识库）；
2. 至少创建一个知识库（`公开可见`）并发布一篇文档（`已发布`）。

> 前台取数通过插件注入的 `${minidocsFinder}` 完成（列表 / 详情 / 文档树），详见 [`minidocs-theme-api.md`](./minidocs-theme-api.md) 与 [`minidocs-rest-api.md`](./minidocs-rest-api.md)。

### 23.5 代码高亮依赖 `plugin-shiki`

| 插件           | 用途                                     | 必需度             |
| -------------- | ---------------------------------------- | ------------------ |
| `plugin-shiki` | 基于 Shiki 的代码块高亮，支持亮 / 暗主题 | 代码块高亮**必需** |

在后台插件设置中配置亮 / 暗主题，主题本身不提供该选项。若未安装，代码块将以纯文本无高亮形式展示。

### 23.6 插件一览速查

| 插件                 | 影响功能                              | 未装时降级                    |
| -------------------- | ------------------------------------- | ----------------------------- |
| `plugin-links`       | 友链页、侧边栏友链 / 订阅、RSS 资讯页 | 模块自动隐藏 / 显示「未启用」 |

## 24. 常见问题

### Q1 如何完全离线部署？

下载字体文件上传到 Halo **附件管理**，在「主题样式 → 字体 CSS 地址」替换为本地附件路径；图标字体已内置，无需额外处理。若使用 iconfont，把 iconfont CSS 与字体文件一同托管在附件管理中。

### Q2 动态背景影响性能吗？

Canvas 2D 渲染，粒子数随屏幕自动调整，几乎无影响；如顾虑可降低透明度或切静态背景图（「页面背景 → 背景类型 = 自定义背景图」）。移动端默认关闭动态背景以省电。

### Q3 为什么友链 / RSS 页没有内容？

按顺序排查：

1. 确认已安装并启用 `plugin-links`；
2. 在插件「RSS 订阅」中开启「公开 RSS 订阅动态」；
3. 至少添加一条友链并配置其 RSS 源；
4. 清缓存刷新前台。

### Q4 侧边栏模块顺序怎么调？

在「侧边栏设置 → 侧边栏模块顺序」拖拽每行调整；删除某行隐藏该模块，可重加。各模块单独开关（`show_author` / `show_announcement` 等）用于临时显隐，不影响顺序。

### Q5 博主背景图和背景色区别？

- **背景图**：适合深色图（文字自动变白 + 半透明遮罩），视觉冲击力强。
- **背景色**：更简洁，纯色块 + 白字，加载更快。
- **同时设置时背景图优先**，背景色被忽略。

### Q6 切换明暗模式后配色异常？

主题的「浅色模式 / 深色模式」两组配置是独立的。若你只配置了浅色模式，深色模式会使用内置默认值（通常没问题）。如出现配色冲突，检查对应模式的背景图、遮罩色、文字色是否搭配合理。

### Q7 文章正文 H1 不显示怎么办？

检查「文章页面 → 显示文章内容里的 H1 级标题」是否被关闭。该选项关闭后，正文里手写的 H1 不再渲染显示。若希望 H1 进入右侧目录，则开启「右侧目录显示 H1 级标题」。两者相互独立。

### Q8 菜单图标不显示？

按以下顺序排查：

1. 确认菜单项注解 `icon` 已填写且非空；
2. 确认图标类名与当前图标库（「主题样式 → 图标库」）匹配；
3. 若用 Iconify，到 [icon-sets.iconify.design](https://icon-sets.iconify.design) 核对图标名拼写；
4. 若用 iconfont，确认 `icon_css_url` 已正确填写且可访问。

### Q9 如何让友链页支持在线申请？

在线申请由 `plugin-links` 插件提供。安装并在插件设置中开启「在线申请」后，前台「申请友链」按钮会弹出在线表单；未开启时则按本主题「友情链接页设置」中的 `apply_email` / `apply_url` 兜底。

### Q10 主题升级会丢失配置吗？

不会。Halo 主题的设置存储在独立的 ConfigMap 中，升级主题 ZIP 只更新模板与静态资源，已配置的设置项会被保留。建议升级前仍备份一份 `theme.config`（后台可导出）。

### Q11 知识库页（`/docs`）打不开或没有内容？

按顺序排查：

1. 确认已安装并启用 `plugin-minidocs`（MiniDocs）插件（下载地址：[halo-plugin-minidocs Releases](https://github.com/cosolar/halo-plugin-minidocs/releases)）；
2. 在插件设置中开启「允许未登录用户阅读」（否则游客访问会被拒绝）；
3. 至少创建一个知识库，并将其设为**公开可见**；
4. 知识库内至少有一篇 `已发布`（`phase=published`）的文档；
5. 清缓存刷新 `/docs`。

> 未登录访客只能看到公开知识库；私有知识库仅对其创建者 / 成员 / 管理者（需登录）可见。

### Q12 图库页没有照片或看不到上传按钮？

- **没有照片**：确认已安装并启用 `plugin-photos`，并在图库后台上传过照片。
- **看不到上传按钮**：受「图库页设置 → 显示操作按钮」控制，且**仅对已登录用户**生效。请确认开关为 `true` 且当前已登录。
